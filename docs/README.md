# Documentation Index

Red Frontier is planned as a complete Mars mission-design game. This index separates the game vision and production roadmap from research, implementation evidence, and asset QA.

## Game and production

- [Game brief](GAME_BRIEF.md): full mission concept, player journey, target MVP, and current implementation boundary.
- [Production plan](PLAN.md): facility layout, art pipeline, and environment decisions.
- [Production inventory](PRODUCTION_INVENTORY.md): completed foundation and remaining game systems.
- [Visual language](VISUAL_LANGUAGE.md): locked rules for the six-space facility.
- [Game readiness](GAME_READINESS.md): performance, streaming, validation, and known runtime caveats.

## Data and science

- [Data ledger](DATA_LEDGER.md): candidate data-to-game mappings, verification notes, licensing considerations, and integration roadmap. Source research is not proof that a dataset is already used at runtime.
- [Data sources](DATA_SOURCES.md): primary source links and project attribution references.

## Rover and integration

- [Rover integration](ROVER_INTEGRATION.md): canonical rover asset, runtime path, placement contract, and verification.
- [Perseverance build report](../art/qa/PERSEVERANCE_BUILD_REPORT.md): modeling references, export checks, credits, and fidelity limits.
- [Rover QA report](../art/qa/QA_REPORT.md): static geometry/export review and its scope limits.
- [Mobility review](../art/qa/mobility_realism_review.md), [science review](../art/qa/science_review.md), and [systems review](../art/qa/systems_review.md): component-level evidence and accepted approximations.
- [Character workspace](../art/character/README.md): RF-01 engineer asset pipeline and checkpoints.
